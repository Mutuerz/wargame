# Announcer voice lines (optional)

Drop MP3 files here to replace the browser's built-in speech voice for the multi-kill callouts:

| File | Line |
| --- | --- |
| `double.mp3` | Double kill! |
| `triple.mp3` | Triple kill! |
| `quadra.mp3` | Quadra kill! |
| `penta.mp3` | Pentakill! |

Any text-to-speech site or your own recording works. Keep each clip short (under 2 seconds).
Missing files fall back to the browser voice.
